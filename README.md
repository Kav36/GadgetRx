# 📱💻 GadgetRx - Electronics Repair Management System

**GadgetRx** is a **web-based platform** designed to help users find and manage **laptop, computer, and mobile phone repair services** efficiently. Built with **Node.js, MySQL, HTML, and CSS**, this system streamlines repair requests, tracks service status, and enhances customer experience.

---

## 🚀 Features
✅ **User-Friendly Interface** – Clean and responsive UI with HTML & CSS.  
✅ **Repair Booking System** – Customers can book repair services online.  
✅ **Service Tracking** – Track repair progress in real time.  
✅ **Technician Management** – Assign and manage technicians for repairs.  
✅ **Database Integration** – MySQL backend for managing users, services, and repairs.  
✅ **Authentication** – Secure login system for customers and technicians.  
✅ **Admin Dashboard** – Manage repair requests, customers, and service history.  

---

## 🛠 Tech Stack
- **Frontend**: HTML, CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MySQL  
- **Authentication**:   
- **Hosting**: Can be deployed on **Heroku, AWS, or DigitalOcean**
